AWAN SPACE - FRONTEND ONLY

Cara buka:
1. Ekstrak ZIP.
2. Buka file index.html langsung di browser.

Tidak ada backend.
Tidak perlu npm install.
Tidak perlu npm start.
Tidak perlu database.

Catatan:
- Semua data tersimpan di browser memakai localStorage.
- Spotify player memakai embed resmi Spotify.
- Kalau Spotify iframe tidak tampil saat dibuka dari file://, buka folder ini dengan Live Server VS Code. Itu hanya server statis, bukan backend aplikasi.
